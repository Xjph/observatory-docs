# Photographer Downloads

## Latest

### v1.1.3

This release of photographer fixes some UI issues in the "Process" window, mostly with the "Separate Output" checkbox, which both liked to wander around the window, and not properly reflect its saved state. The filename preview should also now use available space when then window is resized.

In addition there is a speculative fix for an error that can happen during a read-all if Photographer steps on its own toes, as well as a performance optimization when using the automatic location finding for watermarks or text.

Release versions:
